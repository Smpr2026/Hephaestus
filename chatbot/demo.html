SMPR Assistant — chatbot demo

A working prototype of the customer chatbot for Sydney Mobile Phone Repairs. Every answer comes from knowledge-base.json — the same file that feeds the production system prompt. Click any question on the right, or type your own in the widget.

⚠ Demo — verify prices & address before launch

What this demo is. The widget bottom-right is the real UI, running a deterministic matcher over the knowledge base so it works offline with no API key. In production the same knowledge base is injected into a Claude system prompt (see system-prompt.md), which handles the messy phrasings a keyword matcher misses.

How to read it. Turn on Show matched intent below to see which knowledge-base entry produced each answer — that's how you audit coverage and spot the gaps.

  • Prices come from the pricing.repairs table. Where a price is null the bot says it doesn't know and gives the phone number — it never guesses.
  • Anything it can't answer falls back to call {{phone}} / walk in to the shop.
  • iCloud bypass, stolen devices and spyware requests are refused by design.
